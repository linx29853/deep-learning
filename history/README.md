# CNN 原始提交历史

`cifar10-CNN.bundle` 保存原仓库 main 分支的 7 个提交，末端提交为 `caad0eb2e05635d2285c087f9a315cf4af7bd799`。

来源：[linx29853/cifar10-CNN](https://github.com/linx29853/cifar10-CNN)。原仓库保持原样。

在新目录恢复历史：

```bash
git init cnn-original
git -C cnn-original fetch ../history/cifar10-CNN.bundle refs/remotes/origin/main:refs/heads/main
git -C cnn-original switch main
```
