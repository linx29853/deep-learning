# 随机水平翻转对照实验

两组使用相同网络、Adam 优化器、学习率 0.001、批量大小 64、随机种子 42，均从头训练 10 轮。数据划分固定为 45,000 张训练图、5,000 张验证图和 10,000 张测试图。唯一实验因素为训练图片是否进行概率 0.5 的随机水平翻转；验证和测试均仅使用 ToTensor。

## 运行

在项目目录、lerobot 环境下，依次执行：

```bash
python train.py --epochs 10 --augmentation none --run-name baseline-10ep
python train.py --epochs 10 --augmentation hflip --run-name hflip-10ep
```

两组模型初始化种子一致，训练批次顺序使用独立生成器，以避免随机翻转改变数据抽样顺序。GPU 运算仍可能存在微小非确定性。此前十轮实验可用于参考；本轮无增强实验用于与增强实验匹配更新后的数据抽样流程。

## 输出

每组保存至各自的 `runs/<run-name>/`：

- `config.json`：实验配置。
- `train-source.py`：本次训练代码快照。
- `metrics.csv`：每轮训练与验证损失、准确率，准确率使用 0～1 小数。
- `best.pt`：验证准确率最高的模型。
- `summary.json`：最佳轮次、最佳验证准确率及最终测试指标。

已有实验目录会拒绝覆盖，重新运行使用新名称。两组均与旧的 `cifar10-best.pt` 独立。

## 比较方法

主要比较最佳验证准确率、后期训练与验证差距及损失趋势。增强效果依据实际结果判断，训练准确率下降本身不表示失败。当前脚本每次结束后报告测试结果；后续选择方案以验证集为依据，方案确定后再做最终测试。结果波动可通过多组相同种子的配对实验进一步评估。
